# 书刊14 机关权术一百招斗争团结与周旋

> 机关实用·权术

## 关于本书

庙算出自孙子兵法：未战而庙算胜者，得算多也。本书把庙算落进现代组织日常：一百招，每招解决一个具体博弈场景。体例为招式卡片：招名、场景、机制（为何有效）、用法、风险（何时反噬）、出处（博弈论或史例）。卷次按场景分：办文局、会务局、关系局、信息局、危机局。理论底座是信号理论与昂贵承诺模型，但每招以周一早上能不能用为检验标准。
